## Задача 1. Сложение матриц без NumPy

В научной лаборатории проводятся измерения температуры в разных точках исследовательской станции. Результаты каждого измерения записываются в виде прямоугольной таблицы — матрицы.

В коде уже заданы две матрицы одинакового размера (например, `matrix1` и `matrix2`). Напиши программу, которая складывает соответствующие элементы этих матриц **без использования библиотеки NumPy**.

**Формат вывода**
Вывести результирующую матрицу. Каждая строка матрицы должна выводиться на отдельной строке, элементы разделяются пробелами.

**Пример матриц в коде:**
```python
matrix1 = [
    [1, 2, 3],
    [4, 5, 6]
]

matrix2 = [
    [7, 8, 9],
    [1, 2, 3]
]
```

**Ожидаемый вывод:**
```
8 10 12
5 7 9
```

**Ограничения:**
- Использование библиотеки `NumPy` запрещено.

## Задача 2. Умножение матриц без NumPy

На космической станции работает автоматическая система обработки сигналов. Каждый сигнал записывается в матрицу. Для преобразования сигналов используется матрица коэффициентов.

В коде заданы две матрицы: `matrix1` и `matrix2`. Напиши программу, которая вычисляет их произведение **без использования библиотеки NumPy**.

Напомним: умножение возможно, только если количество столбцов первой матрицы совпадает с количеством строк второй.

**Формат вывода**
Если умножение возможно — вывести результирующую матрицу (каждый ряд с новой строки, числа через пробел).
Если умножение невозможно — вывести `ERROR`.

**Пример матриц в коде:**
```python
matrix1 = [
    [1, 2, 3],
    [4, 5, 6]
]

matrix2 = [
    [7, 8],
    [9, 10],
    [11, 12]
]
```

**Ожидаемый вывод:**
```
58 64
139 154
```

**Ограничения:**
- Использование библиотеки `NumPy` запрещено.

## Задача 3. Умножение матриц с NumPy

Искусственный интеллект управляет системой распознавания объектов на спутнике. Для обработки информации используются матричные преобразования.

В коде заданы две матрицы: `matrix1` и `matrix2`. Напиши программу, которая вычисляет их произведение с помощью библиотеки `NumPy`. Умножение вручную (вложенными циклами) **запрещено**.

**Формат вывода**
Если умножение возможно — вывести результирующую матрицу (каждый ряд с новой строки, числа через пробел).
Если невозможно — вывести `ERROR`.

**Пример матриц в коде:**
```python
matrix1 = [
    [2, 1],
    [3, 4]
]

matrix2 = [
    [1, 2, 3],
    [4, 5, 6]
]
```

**Ожидаемый вывод:**
```
6 9 12
19 26 33
```

**Ограничения:**
- Необходимо использовать библиотеку `NumPy`.

## Задача 4. Архив потерянных экспедиций

В далёком будущем человечество отправило множество экспедиций к неизвестным планетам. Каждая экспедиция вела журнал найденных минералов.

В коде задан список журналов экспедиций — `expeditions`. Каждый журнал — это список названий минералов. Напиши программу, которая создаёт единый каталог, в котором каждый минерал встречается **только один раз**.

**Формат вывода**
Вывести названия всех уникальных минералов, по одному на строке. Порядок вывода не имеет значения.

**Пример данных в коде:**
```python
expeditions = [
    ["Кварц", "Алмаз", "Рубин", "Кварц"],
    ["Рубин", "Изумруд", "Сапфир"],
    ["Алмаз", "Топаз", "Сапфир"]
]
```

**Возможный вывод:**
```
Кварц
Алмаз
Рубин
Изумруд
Сапфир
Топаз
```

**Ограничения:**
- Регистр символов учитывается: `Кварц` и `кварц` — разные названия.

## Задача 5. Сбой системы пропусков

В крупном научном комплексе система контроля доступа записывает идентификаторы пропусков, которые проходят через контрольный пункт. После сбоя нужно понять, какие идентификаторы встречаются чаще одного раза.

В коде задан список идентификаторов — `logs`. Напиши программу, которая определяет:
- сколько **различных** идентификаторов встретилось более одного раза;
- сколько всего записей приходится на эти повторяющиеся идентификаторы (включая первые появления).

**Формат вывода**
Вывести два целых числа через пробел.
Если повторяющихся идентификаторов нет — вывести `0 0`.

**Пример данных в коде:**
```python
logs = [101, 205, 101, 307, 205, 101, 408, 509]
```

**Ожидаемый вывод:**
```
2 5
```

**Ограничения:**
- `1 ≤ n ≤ 100000`
- `1 ≤ идентификатор ≤ 1000000000`
