## Задача 1. «Поворот матрицы на 90°»

**Контекст.** На спутнике матрица сенсора приходит в «сыром» виде, и её нужно повернуть на 90° по часовой стрелке.

**Дано:**

```python
m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

**Что сделать.** Повернуть матрицу на 90° по часовой стрелке и вывести результат.

**Ожидаемый вывод:**

```
7 4 1
8 5 2
9 6 3
```

**Подсказка.** Подумайте, как связаны координаты элемента до и после поворота: элемент `m[i][j]` после поворота на 90° по часовой стрелке попадает в позицию `result[j][n-1-i]`, где `n` — размер матрицы. Проверьте на угловых элементах.

## Задача 2. «Разреженная матрица: хранить только ненулевое»

**Контекст.** В архиве экспедиций матрица наблюдений огромная, но почти вся состоит из нулей. Нужно сжать её в словарь `{(i, j): value}` только для ненулевых элементов, а потом восстановить обратно.

**Дано:**

```python
m = [
    [0, 0, 5, 0],
    [0, 0, 0, 0],
    [1, 0, 0, 7],
    [0, 0, 0, 0]
]
```

**Что сделать.**

1. Построить словарь `sparse`, где ключ — `(строка, столбец)`, значение — ненулевой элемент.
2. По `sparse` и размерам `rows, cols` восстановить полную матрицу `full`.
3. Вывести `sparse` (отсортированный по ключу) и `full`.

**Ожидаемый вывод (пример формата):**

```
(0, 2): 5
(2, 0): 1
(2, 3): 7
---
0 0 5 0
0 0 0 0
1 0 0 7
0 0 0 0
```

**Подсказка.** Подумайте, как из `sparse` узнать размеры, если бы вы их не знали. И почему `dict` удобнее списка списков для разреженных данных.

## Задача 3. «Седловая точка матрицы»

**Контекст.** В матрице измерений нужно найти «седловую точку» — элемент, который **минимален в своей строке** и **максимален в своём столбце** (или наоборот). Таких может быть несколько или ни одного.

**Дано:**

```python
m = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

**Что сделать.** Найти все седловые точки (мин в строке + макс в столбце) и вывести их координаты и значения. Если нет — вывести `NO`.

**Ожидаемый вывод:**

```
NO
```

(для этой матрицы седловых точек нет — проверьте руками)

**Подсказка.** Сначала найдите минимум каждой строки и максимум каждого столбца, потом пересеките условия. Подумайте про случай, когда минимум в строке встречается дважды.

## Задача 4. «Умножение матриц по модулю и переполнение»

**Контекст.** В системе обработки сигналов числа могут быть огромными, поэтому все операции делаются **по модулю `MOD`**. Нужно перемножить две матрицы, но каждое промежуточное произведение и сумму брать по модулю, чтобы не было переполнения.

**Дано:**

```python
MOD = 10**9 + 7
matrix1 = [[10**9, 10**9], [10**9, 10**9]]
matrix2 = [[10**9, 10**9], [10**9, 10**9]]
```

**Что сделать.** Вычислить `matrix1 @ matrix2 mod MOD` **без NumPy** и вывести результат.

**Ожидаемый вывод:**

```
(посчитайте сами — но каждое произведение (10^9)^2 огромно, поэтому важно брать % MOD на каждом шаге)
```

**Подсказка.** `(a*b) % MOD` и `(a+b) % MOD` — применяйте на каждом шаге внутреннего цикла. Подумайте, почему `sum(...) % MOD` в конце **не эквивалентно** взятию модуля на каждом шаге в общем случае (для Python — эквивалентно из-за big-int, но для C/фиксированных типов — нет). Это задача на понимание, а не на трюк.

## Задача 5. «Слияние журналов с подсчётом частот»

**Контекст.** У вас есть несколько журналов экспедиций (списки минералов). Нужно построить сводку: для каждого минерала — в скольких **разных журналах** он встречается (повтор внутри одного журнала считается один раз), и отсортировать по убыванию частоты, при равенстве — по алфавиту.

**Дано:**

```python
expeditions = [
    ["Кварц", "Алмаз", "Рубин", "Кварц"],
    ["Рубин", "Изумруд", "Сапфир"],
    ["Алмаз", "Топаз", "Сапфир", "Кварц"]
]
```

**Что сделать.** Вывести строки вида `минерал: N`, где `N` — число журналов, в которых он встретился. Сортировка: по `N` убыв., затем по имени.

**Ожидаемый вывод:**

```
Кварц: 2
Алмаз: 2
Рубин: 2
Сапфир: 2
Изумруд: 1
Топаз: 1
```
