
# Задача 1. «Сдвиг и срез»

**Дано:**

```python
nums = [1, 2, 3, 4, 5, 6, 7]
k = 3
```

**Что сделать (срезами):**

1. Сдвинуть список вправо на `k` позиций (циклически) и вывести результат.
2. Вывести «зеркальную» перестановку: первый с последним, второй с предпоследним и т.д. (т.е. `[7, 6, 5, 4, 3, 2, 1]` — но соберите её именно срезами, не через `[::-1]`... хотя `[::-1]` — тоже срез, подумайте, как ещё).
3. Разбить список на пары `(nums[i], nums[i+1])` через срезы `nums[::2]` и `nums[1::2]`, собрать список кортежей (последний элемент без пары — добавьте `None`).

**Ожидаемый вывод:**

```
Сдвиг вправо на 3: [5, 6, 7, 1, 2, 3, 4]
Зеркало: [7, 6, 5, 4, 3, 2, 1]
Пары: [(1, 2), (3, 4), (5, 6), (7, None)]
```

## Задача 2. «Уникальные с сохранением порядка + пересечение списков»

**Дано:**

```python
words1 = ["кот", "пёс", "кот", "лис", "пёс", "волк"]
words2 = ["пёс", "тигр", "кот", "медведь", "пёс", "лис"]
```

**Что сделать:**

1. Дедуплицировать `words1` с сохранением порядка.
2. Вывести пересечение `words1` и `words2` **в порядке первого появления в `words1`** (без сортировки).
3. Вывести элементы, которые есть только в `words1`, тоже в порядке первого появления.
4. Проверить: правда ли, что мощность пересечения = `len(set(words1) & set(words2))`? Вывести `True/False`.

**Ожидаемый вывод:**

```
Уникальные words1: ['кот', 'пёс', 'лис', 'волк']
Пересечение (в порядке words1): ['кот', 'пёс', 'лис']
Только в words1 (в порядке words1): ['волк']
Проверка: True
```

## Задача 3. «Скользящее окно: среднее и уникальные»

**Дано:**

```python
temps = [10, 12, 11, 15, 14, 13, 16]
k = 3
```

**Что сделать:**

1. Для каждого окна длины `k` (срезами `temps[i:i+k]`) вычислить среднее **в целых числах** (`sum // k`).
2. Собрать средние в список `avgs`.
3. Вывести `avgs`.
4. Вывести множество уникальных средних.
5. Найти окно с максимальным средним и вывести его индекс и сам срез.

**Ожидаемый вывод:**

```
Средние: [11, 12, 13, 14, 14]
Уникальные средние: {11, 12, 13, 14}
Максимум: индекс 3, окно [15, 14, 13]
```
