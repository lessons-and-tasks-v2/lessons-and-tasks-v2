## Задача №1 «Пирамида MMR»

— Построй пирамиду из звёзд, — приказал Инвокер. — Ровную, как рейтинг в топ-100.

Напиши программу, которая:
1. Считывает число `N` — высоту пирамиды.
2. Выводит `N` строк. В первой строке — одна звёздочка, во второй — две, в третьей — три и так далее до `N`.
3. Звёзды в строке разделены пробелом. **После последней звёздочки пробела быть не должно.**

**Формат ввода**
Одно целое число N.

**Формат вывода**
N строк с увеличивающимся количеством звёзд.

| Ввод | Вывод |
| :--- | :--- |
| 4 |   * |
| |   * * |
| |  * * * |
| | * * * * |

Одно нечётное целое число N.

Ромб из звёзд.

| Ввод | Вывод |
| :--- | :--- |
| 5 | * |

| | * * * |
| | * * |

## Задача №3 «Таймер с ускорением»

— Время матча идёт неравномерно, — сказал Тоби. — Каждую минуту таймер ускоряется.

Напиши программу, которая:
1. Считывает число `N` — сколько секунд длится матч.
2. Выводит секунды от `1` до `N`, но с ускорением: каждая следующая секунда выводится **столько раз**, сколько она сама (то есть `1` — один раз, `2` — два раза, `3` — три раза и так далее).
3. Каждое число — на новой строке.

**Подсказка:** здесь нужен вложенный цикл — внешний идёт по секундам, внутренний повторяет вывод.

**Формат ввода**
Одно целое число N.

**Формат вывода**
Последовательность чисел с повторами.

| Ввод | Вывод |
| :--- | :--- |
| 3 | 1 |
| | 2 |
| | 2 |
| | 3 |
| | 3 |
| | 3 |

## Задача №6 «Проверка состава»

1. Считывает число `N` — сколько героев должно быть.

1. Число N.
2. N строк.

**Формат вывода**
Одна строка.

| Ввод | Вывод |
| :--- | :--- |
| 3 | ГЕРОЙ ПРОПАЛ |
| Инвокер | |
| | |
| Пудж | |

| Ввод | Вывод |
| :--- | :--- |
| 3 | ВСЕ НА МЕСТЕ |
| Инвокер | |

1. Считывает число `N` — сколько игроков в команде.

Три строки: список, сумма, максимум.

| Ввод | Вывод |
| :--- | :--- |
| 4 | [300, 900, 150, 600] |
| 300 | 1950 |
| 900 | 900 |
