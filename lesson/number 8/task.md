## Задача №1 «Секретный маршрут»

— Нам нужно добраться до базы противника, — сказал Кул. — Я записал координаты всех контрольных точек, но некоторые из них оказались одинаковыми. Давай найдём самую дальнюю точку и узнаем, сколько раз она встречается в маршруте. А ещё мне нужно проверить, есть ли среди координат одна особенная.

Напиши программу, которая считывает количество координат и сами координаты, сохраняет их в кортеж. Затем программа должна найти максимальную и минимальную координаты, вывести, сколько раз максимальная координата встречается в кортеже, и определить индекс её первого появления. В конце нужно проверить, содержится ли заданное число в кортеже.

Формат ввода

Вводится число N — количество координат (N ≥ 1). Затем N целых чисел — координаты контрольных точек. После этого вводится число K, которое нужно найти в кортеже.

Формат вывода

Вывести исходный кортеж, максимальную и минимальную координаты через пробел, количество повторений максимальной координаты, индекс её первого появления и `True` или `False` в зависимости от наличия K в кортеже.

| Ввод | Вывод           |
| ---- | --------------- |
| 5    | (3, 9, 5, 9, 2) |
| 3    | 9 2             |
| 9    | 2               |
| 5    | 1               |
| 9    | True            |
| 2    |                 |
| 5    |                 |

## Задача №2 «Турнир двух команд»

— Сегодня состоится большой турнир! — объявил Кул. — Две команды собрали своих игроков, но некоторые умудрились записаться сразу в обе. Нужно узнать, кто состоит в обеих командах, кто участвует хотя бы в одной и сколько игроков выступают только за одну команду.

Напиши программу, которая считывает составы двух команд и сохраняет их во множества. Затем нужно найти количество игроков, которые присутствуют в обеих командах, общее количество уникальных участников турнира и количество игроков, состоящих только в одной из двух команд. После этого программа должна проверить, состоит ли заданный игрок одновременно в обеих командах.

Формат ввода

Вводится число N — количество игроков первой команды, затем N строк с их именами. Далее вводится число M — количество игроков второй команды и M строк с их именами. В конце вводится имя игрока для проверки.

Формат вывода

Вывести четыре строки: количество общих игроков, количество уникальных участников, количество игроков, состоящих только в одной команде, и `True` или `False` в зависимости от того, состоит ли заданный игрок в обеих командах.

| Ввод  | Вывод |
| ----- | ----- |
| 3     | 2     |
| Кул   | 4     |
| Макс  | 2     |
| Алекс | True  |
| 3     |       |
| Алекс |       |
| Кул   |       |
| Дэн   |       |
| Кул   |       |

## Задача №3 «Рейтинг бойцов»

— Турнир завершён! — сказал Кул. — Теперь нужно посчитать результаты всех участников. У каждого бойца есть очки, но за победу в финальном раунде полагается дополнительная награда. Давай начислим бонус и выясним, кто набрал больше всего очков!

Напиши программу, которая считывает имена бойцов и их очки, сохраняя данные в словарь. Затем программа должна с помощью цикла `for` пройти по словарю и прибавить каждому бойцу 10 бонусных очков. После этого нужно с помощью цикла найти бойца с максимальным количеством очков. Если несколько бойцов набрали одинаковое максимальное количество очков, победителем считается тот, кто был добавлен в словарь раньше. В конце программа должна вывести обновлённые результаты всех бойцов и имя победителя вместе с его очками.

Формат ввода

Вводится число N — количество бойцов (N ≥ 1). Далее для каждого бойца вводятся две строки: имя и количество очков (целое число). Имена всех бойцов уникальны.

Формат вывода

Вывести имена всех бойцов и их обновлённые очки в формате `Имя: очки`, сохраняя порядок ввода. На последней строке вывести имя победителя и его очки через тире.

| Ввод  | Вывод     |
| ----- | --------- |
| 3     | Кул: 60   |
| Кул   | Макс: 90  |
| 50    | Алекс: 70 |
| Макс  | Макс — 90 |
| 80    |           |
| Алекс |           |
| 60    |           |
