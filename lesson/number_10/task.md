## Задача 1. «Хроники Мультивселенной»

Библиотека Невидимого Университета содержит хроники бесчисленных миров. Каждый мир описывается набором ключевых событий. Некоторые события повторяются в разных мирах — это «узловые точки», где судьба ветвится одинаково.

Напиши программу, которая найдёт события, встречающиеся **ровно в одном** мире (уникальные для данного мира), и выведет их.

**Формат ввода**
Целое число `n` — количество миров.
Далее `n` раз:
- целое число `m` — количество событий в мире;
- `m` строк — названия событий.

**Формат вывода**
Вывести названия событий, которые встречаются только в одном мире, каждое с новой строки. Порядок неважен.

## Задача 2. «Инвентарь волшебника»

У каждого волшебника Плоского мира есть сумка с ингредиентами. Ингредиенты измеряются в «порциях» — целых числах. Если два волшебника встречаются и у обоих есть ингредиент с одинаковым числом порций, то происходит «магический резонанс» — и все такие порции исчезают у обоих.

Определи, какие порции останутся, если все волшебники высыпят содержимое сумок в общий котёл. Ингредиент остаётся, только если его число порций не встречается ни у одного другого волшебника.

**Формат ввода**
Вводятся строки, пока не встретится пустая строка. Каждая строка — это числа (порции ингредиентов одного волшебника), разделённые пробелом. Волшебники разделяются строкой с числом `0`.

**Формат вывода**
Вывести в одной строке через пробел все числа, которые не повторялись у разных волшебников. Каждое число — один раз. Порядок неважен.

## Задача 3. «Палитра Создателя»

Боги создают цвета для новых миров. Каждый бог задаёт свой набор цветов в формате RGB (например, `#FFAA00`). Цвет считается «нестабильным», если он встречается **более чем в половине** наборов.

Напиши программу, которая найдёт все нестабильные цвета и выведет их вместе с количеством наборов, в которых они встречаются.

**Формат ввода**
Целое число `k` — количество богов (наборов).
Далее `k` раз:
- целое число `m` — количество цветов у бога;
- `m` строк — цвета в шестнадцатеричном формате.

**Формат вывода**
Для каждого нестабильного цвета вывести строку: `цвет количество`. Цвета выводить в порядке первого появления. Если нестабильных цветов нет — вывести `нет`.

## Задача 4. «Слоны и черепахи»

В одном из миров Великий А'Туин решил провести перепись: каждый слон держит на себе набор «дисков» (миров). Диски нумеруются целыми числами. Если два слона держат диски с одинаковым номером, то эти диски «схлопываются» в сингулярность и исчезают у обоих слонов.

Определи, какие номера дисков останутся после того, как все слоны встанут в ряд и «сверят» свои наборы. Диск остаётся, если его номер не встречается ни у одного другого слона.

**Формат ввода**
Вводятся строки, пока не будет введена пустая строка. Каждая строка — номера дисков одного слона, разделённые пробелом. Слоны разделяются строкой `-2`.

**Формат вывода**
Вывести в одной строке через пробел все номера дисков, которые не повторялись у разных слонов. Каждый номер — один раз. Порядок неважен.

## Задача 5. «Заклинания и контрзаклинания»

В школе волшебства изучают заклинания. Каждое заклинание имеет числовой код. Если в разных группах встречаются заклинания с одинаковым кодом, то они взаимно нейтрализуются (исчезают все экземпляры с этим кодом из всех групп).

Напиши программу, которая определит, какие коды заклинаний останутся после «слияния» всех групп. Код остаётся, только если он встречается ровно в одной группе (внутри группы повторы допустимы — это одно и то же заклинание).

**Формат ввода**
Целое число `g` — количество групп.
Далее `g` раз:
- целое число `m` — количество заклинаний в группе;
- `m` целых чисел — коды заклинаний.

**Формат вывода**
Вывести в одной строке через пробел все коды, которые не повторялись в разных группах. Каждый код — один раз. Порядок неважен. Если таких нет — вывести пустую строку.
