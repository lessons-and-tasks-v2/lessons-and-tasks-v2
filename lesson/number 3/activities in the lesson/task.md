# Часть 1. Циклы (7 задач)

## Задача №1 «Перекличка в Братстве»

— Нас девять, — сказал Элронд. — Пересчитайте всех по порядку.

Напиши программу, которая:
1. Считывает число `N`.
2. С помощью цикла `for` выводит числа от `1` до `N` включительно, каждое на новой строке.

**Формат ввода**
Одно целое число N.

**Формат вывода**
Числа от 1 до N, каждое на новой строке.

| Ввод | Вывод |
| :--- | :--- |
| 3 | 1<br>2<br>3 |

## Задача №6 «Проверка сведений»

— Если хоть одно донесение ложное, — сказал Гэндальф, — останови проверку.

Напиши программу, которая:
1. Считывает число `N`.
2. В цикле считывает `N` чисел.
3. Если встретилось **отрицательное** число — вывести `ЛОЖНОЕ ДОНЕСЕНИЕ` и **немедленно прекратить** проверку.

Одна строка с результатом.

| Ввод | Вывод |
| :--- | :--- |
| 3 | ЛОЖНОЕ ДОНЕСЕНИЕ |
| 5 | |
| -2 | |
| 7 | |

| Ввод | Вывод |
| :--- | :--- |
| 3 | ВСЕ ДОНЕСЕНИЯ ВЕРНЫ |
| 5 | |
| 2 | |
| 7 | |

## Задача №10 «Обратное заклинание» — сборка новой строки в цикле

— Чтобы разрушить чары, — сказал Гэндальф, — произнеси слово наоборот. Но срезы использовать нельзя.

Напиши программу, которая:
1. Считывает строку.
2. С помощью цикла строит её **обратный** вариант.
3. Выводит результат.

Срезы (`[::-1]`) и `reversed()` использовать **нельзя**.

**Формат ввода**
Одна строка.

**Формат вывода**
Обратная строка.

| Ввод | Вывод |
| :--- | :--- |
| Шир | риШ |
| Мордор | родроМ |
