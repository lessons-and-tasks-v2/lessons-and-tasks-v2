## Задача №1 «Тег клана»

— В пабе не пускают без тега, — сказал Инвокер. — Но тег должен соответствовать правилам. Проверь его.

Напиши программу, которая считывает одну строку — предполагаемый тег клана — и проверяет его **по порядку** (первое нарушение — стоп):

1. Запршивает тег (строку)
2. Если длина от 3 до 10 символов. Иначе вывести `НЕВЕРНАЯ ДЛИНА`.
2. Только буквы (никаких цифр и знаков). Иначе вывести `ТОЛЬКО БУКВЫ`.
3. Все буквы должны быть в **одном регистре** — либо все заглавные, либо все строчные. Иначе вывести `СМЕШАННЫЙ РЕГИСТР`.
4. Если всё хорошо — вывести тег в **верхнем регистре** и через пробел `— ОК`.

**Формат ввода**
Одна строка.

**Формат вывода**
Одна строка с результатом.

| Ввод | Вывод |
| :--- | :--- |
| NAVI | NAVI — ОК |
| navi | NAVI — ОК |
| NaVi | СМЕШАННЫЙ РЕГИСТР |
| NAVI123 | ТОЛЬКО БУКВЫ |
| Na | НЕВЕРНАЯ ДЛИНА |

## Задача №2 «Модерация Dota-чата»

— За «noob» в чате — мут, — сказал модератор. — Найди и обезвредь.

Напиши программу, которая:
1. Считывает одну строку — сообщение в чате.
2. Считывает еще одну строку — запрещённое слово.
3. Считает, сколько раз запрещённое слово встречается в сообщении (с учётом регистра).
4. Заменяет **каждое** вхождение на звёздочки — столько же звёздочек, сколько символов в запрещённом слове.
5. Выводит две строки:
   - `Замен: <число>`
   - Отфильтрованное сообщение.

**Формат ввода**
1. Сообщение.
2. Запрещённое слово.

**Формат вывода**
Две строки.

| Ввод | Вывод |
| :--- | :--- |
| noob noob go mid | Замен: 2 |
| noob | ****  **** go mid |

## Задача №3 «Шифровальщик реплики» (исправленная)

— Хочу, чтобы мои сообщения в чате выглядели странно, — сказал Пудж. — Закодируй их по правилам.

Напиши программу, которая:
1. Считывает одну строку — реплику.
2. С помощью цикла `for` **без `range` и без `while`** строит новую строку по правилам:
   - **Гласная** (а, е, ё, и, о, у, ы, э, ю, я — в любом регистре) — записывается **два раза подряд** (в исходном регистре).
   - **Согласная** — записывается **один раз** в верхнем регистре.
   - **Пробел** — превращается в `_`.
   - **Цифра** — **пропускается**.
   - **Любой другой символ** — остаётся без изменений.
3. Выводит получившуюся строку.

**Формат ввода**
Одна строка (русские буквы, пробелы, цифры, знаки).

**Формат вывода**
Одна строка — закодированная реплика.

| Ввод | Вывод |
| :--- | :--- |
| иди мид 5 | ииДии_МииД_ |
| я мид! | яя_МииД! |

**Разбор первого примера** по символам:

| Символ | Что это | Что попадает в результат |
| :--- | :--- | :--- |
| `и` | гласная | `ии` |
| `д` | согласная | `Д` |
| `и` | гласная | `ии` |
| ` ` | пробел | `_` |
| `м` | согласная | `М` |
| `и` | гласная | `ии` |
| `д` | согласная | `Д` |
| ` ` | пробел | `_` |
| `5` | цифра | (пропуск) |

| Ввод | Вывод |
| :--- | :--- |
| иди мид 5 | ииДии_МииД_ |
| я мид! | яя_МииД! |

## Задача №4 «Разбор боевого лога»

— Логи после матча — это хаос, — сказал Тоби. — Найди в них важное.

Напиши программу, которая:
1. Считывает одну строку — «лог матча» (там есть буквы, цифры, пробелы и знаки).
2. С помощью цикла `for` **без `range` и без `while`** проходит по каждому символу и считает:
   - сумму всех цифр,
   - минимальную цифру,
   - максимальную цифру,
   - количество букв.
3. Выводит четыре строки:
   - `Сумма цифр: <число>` (или `Цифр нет`, если цифр нет),
   - `Мин: <число>`,
   - `Макс: <число>`,
   - `Букв: <число>`.

**Формат ввода**
Одна строка.

**Формат вывода**
Четыре строки.

| Ввод | Вывод |
| :--- | :--- |
| K5 D3 A12 | Сумма цифр: 11 |
| | Мин: 1 |
| | Макс: 5 |
| | Букв: 3 |
