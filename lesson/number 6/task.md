# Задача №1 «Рейтинг команды» (списки)

— Собери рейтинги всех игроков и найди лучшего, — сказал тренер. — И оформи это красиво.

Напиши программу, которая:

1. Считывает число `N` — сколько игроков в команде.
2. Считывает `N` чисел — рейтинг каждого игрока, сохраняет их в **список**.
3. Выводит список рейтингов.
4. Выводит средний рейтинг (целую часть).
5. Выводит лучший рейтинг и индекс игрока, который его набрал (если таких несколько — первый). Формат: `Лучший: <рейтинг> (индекс <i>)`.

**Формат ввода**

1. Число N.
2. N чисел, каждое на новой строке.

**Формат вывода**
Три строки: список, среднее, лучший игрок.

| Ввод | Вывод                  |
| :--- | :--------------------- |
| 4    | [300, 900, 150, 600]   |
| 300  | 487                    |
| 900  | Лучший: 900 (индекс 1) |
| 150  |                        |
| 600  |                        |

# Задача №2 «Уникальные герои» (множества)

— В матче играли разные герои, — сказал Инвокер. — Но некоторые повторялись. Мне нужны только уникальные.

Напиши программу, которая:

1. Считывает число `N` — сколько героев в первой команде.
2. Считывает `N` имён — герои первой команды, сохраняет их в **множество**.
3. Считывает число `M` — сколько героев во второй команде.
4. Считывает `M` имён — герои второй команды, сохраняет их в **множество**.
5. Выводит оба множества.
6. Выводит количество уникальных героев в каждой команде.
7. Выводит **общих** героев для двух команд и их количество. Оператор `&` использовать **нельзя** — только цикл.

**Формат ввода**

1. Число N.
2. N строк — герои первой команды.
3. Число M.
4. M строк — герои второй команды.

**Формат вывода**
Пять строк: первое множество, второе множество, количество в первом, количество во втором, общие герои и их количество.

| Ввод    | Вывод                          |
| :------ | :----------------------------- |
| 3       | {'Инвокер', 'Пудж', 'Снайпер'} |
| Инвокер | {'Инвокер', 'Снайпер', 'Кул'}  |
| Пудж    | 3                              |
| Снайпер | 3                              |
| 3       | {'Инвокер', 'Снайпер'} — 2     |
| Инвокер |                                |
| Снайпер |                                |
| Кул     |                                |

# Задача №3 «Анализ ника» (строки)

— Ник — это лицо игрока, — сказал Смотритель. — Разбери его по косточкам.

Напиши программу, которая:

1. Считывает одну строку — ник игрока.
2. Выводит количество **букв** в нике (русских и латинских, в любом регистре).
3. Выводит количество **цифр** в нике.
4. Выводит ник **в обратном порядке**.

**Требования:**

- Методы `.isalpha()` и `.isdigit()` использовать **нельзя** — только сравнение символов по диапазонам кодов.
- Срезы (`[::-1]`) и `reversed()` использовать **нельзя** — только цикл.

**Формат ввода**
Одна строка.

**Формат вывода**
Три строки.

| Ввод  | Вывод          |
| :---- | :------------- |
| Dota2 | Букв: 4        |
|       | Цифр: 1        |
|       | Обратно: 2atoD |

### Вопрос 2

### Вопрос 3

Чем `while True` с `break` внутри отличается от `while условие:`? В каких ситуациях первый вариант удобнее, а в каких — опаснее?

### Вопрос 4

Почему `"a" in "abc"` работает, а `"a" in ["a", "b"]` — тоже работает, но по-другому? Объясни разницу между проверкой `in` для строки, списка и множества.

### Вопрос 5
