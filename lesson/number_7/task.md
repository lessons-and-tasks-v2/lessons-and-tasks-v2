## Задача №1 «Инвентарь героя»

— Собери всё, что у меня в инвентаре, — сказал Кул. — И покажи, что можно улучшить. Сначала я хочу увидеть, с чем пришёл в матч. Потом мы купим ещё пару предметов: один отправится в конец сумки, а второй — сразу в начало, чтобы был под рукой. Ну и от какого-то хлама придётся избавиться, чтобы не тащить лишнее.

Напиши программу, которая сначала считает количество предметов в инвентаре и сами предметы, а затем выведет исходный список. После этого она должна считать два новых предмета: первый добавить в конец списка, а второй — в самое начало. Затем программа запрашивает индекс предмета, который нужно выбросить, удаляет его по этому индексу и выводит итоговый список вместе с его длиной.

**Формат ввода**
Вводится число N — количество предметов. Затем N строк с названиями предметов. Далее — новый предмет (добавляется в конец), затем ещё один новый предмет (добавляется в начало) и число K — индекс предмета для удаления.

**Формат вывода**
Вывести исходный список, обновлённый список (после двух добавлений), а затем итоговый список и его длину через тире.

| Ввод | Вывод |
| :--- | :--- |
| 2 | ['Меч', 'Щит'] |
| Меч | ['Лук', 'Меч', 'Щит', 'Посох'] |
| Щит | ['Лук', 'Меч', 'Посох'] — 3 |
| Посох | |
| Лук | |
| 1 | |

## Задача №2 «Профиль игрока»

— Заполни профиль игрока, — сказал Смотритель. — И покажи его целиком.

Напиши программу, которая:
1. Считывает строку — имя игрока.
2. Считывает целое число — его MMR.
3. Считывает строку — его любимую роль.
4. Создаёт **словарь** с ключами `"имя"`, `"mmr"`, `"роль"` и сохраняет в него считанные значения.
5. Выводит словарь целиком.
6. Считывает строку — новый ключ, и строку — значение для него. Добавляет эту пару в словарь.
7. Считывает строку — ключ, значение которого нужно **изменить**, и новое значение. Изменяет его.
8. Считывает строку — ключ, который нужно **удалить** из словаря. Удаляет его.
9. Выводит итоговый словарь и количество ключей в нём.

**Формат ввода**
1. Имя.
2. MMR (целое число).
3. Роль.
4. Новый ключ.
5. Значение для нового ключа.
6. Ключ для изменения.
7. Новое значение.
8. Ключ для удаления.

**Формат вывода**
Две строки: исходный словарь, итоговый словарь и количество ключей.

| Ввод | Вывод |
| :--- | :--- |
| Инвокер | {'имя': 'Инвокер', 'mmr': 6000, 'роль': 'мид'} |
| 6000 | {'имя': 'Инвокер', 'mmr': 6500, 'роль': 'мид', 'клан': 'NAVI'} — 4 |
| мид | |
| клан | |
| NAVI | |
| mmr | |
| 6500 | |
| роль | |

## Задача №3 «Координаты героя»

— Каждый герой стоит на своей позиции, — сказал Инвокер. — И позиция не должна меняться. Запомни это.

Напиши программу, которая:
1. Считывает строку — имя героя.
2. Считывает два целых числа — координаты `x` и `y`.
3. Создаёт **кортеж** из трёх элементов: `(имя, x, y)`.
4. Выводит кортеж целиком.
5. Выводит отдельно имя, `x` и `y` (каждое на новой строке) через обращение по индексу.
6. Выводит длину кортежа.
7. Проверяет, можно ли изменить элементы кортежа. **Использовать `try / except` нельзя.** Вместо этого нужно пройти по кортежу циклом, попытаться записать в каждый элемент новое значение и, если это невозможно (что и должно произойти), вывести `КОРТЕЖ НЕИЗМЕНЯЕМ`. Если хотя бы один элемент удалось изменить — вывести `ИЗМЕНЕНО`.

**Подсказка:** цикл `for` даёт **значение** элемента, но не позволяет его изменить. Чтобы попытаться изменить элемент по индексу, нужен цикл `for i in range(len(tuple))`. Присваивание `tuple[i] = ...` вызовет `TypeError`, который нужно **не перехватывать**, а обработать через `if / else` — проверив, является ли объект кортежем (или сравнив `type`).

**Формат ввода**
1. Имя.
2. Координата x (целое).
3. Координата y (целое).

**Формат вывода**
Кортеж, затем имя, x, y, длина, результат проверки.

| Ввод | Вывод |
| :--- | :--- |
| Инвокер | ('Инвокер', 10, 20) |
| 10 | Инвокер |
| 20 | 10 |
| | 20 |
| | 3 |
| | КОРТЕЖ НЕИЗМЕНЯЕМ |
