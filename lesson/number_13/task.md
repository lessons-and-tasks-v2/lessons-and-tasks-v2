## **Задача 1. Восстановление списка участников экспедиции**

На космической станции проводится проверка состава исследовательской экспедиции. Из-за ошибки системы некоторые участники были записаны несколько раз, а часть зарегистрированных людей не прошла обязательную проверку безопасности.

В коде заданы два списка:

- `participants` — идентификаторы всех зарегистрированных участников (могут повторяться).
- `verified` — идентификаторы участников, прошедших проверку безопасности.

Напиши программу, которая:

1. Находит всех участников, прошедших проверку.
2. Исключает повторяющиеся идентификаторы.
3. Сортирует результат по возрастанию.
4. Определяет количество допущенных участников.

**Формат вывода:** В первой строке вывести количество допущенных участников. Во второй — их идентификаторы через пробел. Если допущенных участников нет, вывести только `0`.

**Пример данных в коде:**

```
participants = [105, 203, 105, 401, 302, 203, 507, 601]verified = [203, 302, 401, 700, 105]
```

**Ожидаемый вывод:**

```
4
105 203 302 401
```

**Ограничения:**

- `1 ≤ n ≤ 100000`
- Идентификаторы — положительные целые числа.
- Исходные списки изменять нельзя.

## **Задача 2. Аномалии в системе наблюдения**

Автоматическая система наблюдения фиксирует идентификаторы объектов, появляющихся в определённой зоне.

Подозрительными считаются объекты, которые были замечены **не менее трёх раз**.

В коде задан список `objects`.

Напиши программу, которая:

1. Находит идентификаторы, встречающиеся не менее трёх раз.
2. Определяет количество появлений каждого такого идентификатора.
3. Сортирует найденные объекты по убыванию количества появлений.
4. Если несколько объектов встречаются одинаковое количество раз, располагает их по возрастанию идентификатора.

**Формат вывода:** Каждая строка содержит идентификатор объекта и количество его появлений через пробел. Если подозрительных объектов нет — вывести `NO ANOMALIES`.

**Пример данных в коде:**

```
objects = [7, 3, 7, 2, 3, 7, 5, 2, 3, 2, 2, 8, 8, 5, 5]
```

**Ожидаемый вывод:**

```
2 4
3 3
5 3
7 3
```

**Ограничения:**

- `1 ≤ n ≤ 100000`
- Каждый подозрительный идентификатор должен выводиться только один раз.
- Порядок элементов исходного списка изменять нельзя.

## **Задача 3. Потерянные книги библиотеки**

После сбоя электронной библиотеки необходимо восстановить список книг, которые когда-либо находились в хранилище, но сейчас отсутствуют.

В коде заданы три списка:

- `catalog` — идентификаторы всех книг, которые когда-либо поступали в библиотеку.
- `available` — идентификаторы книг, которые сейчас находятся в библиотеке.
- `borrowed` — идентификаторы книг, официально выданных читателям.

Книга считается **потерянной**, если она есть в каталоге, но отсутствует и среди доступных книг, и среди выданных.

Напиши программу, которая:

1. Находит все потерянные книги.
2. Исключает повторяющиеся идентификаторы.
3. Сортирует результат по возрастанию.
4. Определяет количество потерянных книг.

**Формат вывода:** В первой строке вывести количество потерянных книг. Во второй — их идентификаторы через пробел. Если потерь нет, вывести только `0`.

**Пример данных в коде:**

```
catalog = [101, 102, 103, 104, 105, 106, 107, 108, 103]available = [101, 102, 105, 108]borrowed = [103, 107]
```

**Ожидаемый вывод:**

```
2
104 106
```

**Ограничения:**

- Каждый список может содержать до `100000` элементов.
- Идентификаторы могут повторяться.
- Книги, которых никогда не было в каталоге, учитывать не нужно.

## **Задача 4. Архив повреждённых последовательностей**

На научной станции хранятся архивы числовых последовательностей. После системного сбоя некоторые элементы были случайно продублированы.

Известно, что до сбоя каждая последовательность состояла из различных чисел, расположенных в порядке первого появления.

В коде задан список `data`.

Напиши программу, которая:

1. Восстанавливает последовательность, оставляя только первое появление каждого числа.
2. Сохраняет исходный порядок уникальных элементов.
3. Создаёт отдельный список чисел, которые встречались более одного раза.
4. Во втором списке каждое число должно присутствовать один раз, а порядок должен соответствовать моменту его **второго появления**.
5. Определяет общее количество лишних элементов, удалённых при восстановлении.

**Формат вывода:** В первой строке вывести восстановленную последовательность. Во второй — список повторявшихся чисел. В третьей — количество удалённых элементов. Если повторений не было, во второй строке вывести `NONE`.

**Пример данных в коде:**

```
data = [4, 7, 2, 4, 9, 7, 4, 3, 2, 8, 9, 9]
```

**Ожидаемый вывод:**

```
4 7 2 9 3 8
4 7 2 9
6
```

**Ограничения:**

- `1 ≤ n ≤ 100000`
- Числа могут быть отрицательными.
- Сортировать исходную последовательность запрещено.
- Порядок обоих результирующих списков имеет значение.

## **Задача 5. Система контроля запрещённых комбинаций**

В лаборатории тестируют химические вещества. Некоторые пары веществ нельзя хранить вместе, поскольку они вступают в опасную реакцию.

В коде заданы:

- `substances` — список идентификаторов веществ, находящихся в хранилище.
- `dangerous_pairs` — список запрещённых пар веществ.

Напиши программу, которая:

1. Определяет, какие запрещённые пары одновременно присутствуют в хранилище.
2. Исключает повторяющиеся пары, даже если они записаны в разном порядке.
3. В каждой найденной паре располагает меньший идентификатор первым.
4. Сортирует пары сначала по первому, затем по второму идентификатору.
5. Выводит количество найденных опасных комбинаций.

**Формат вывода:** В первой строке вывести количество опасных комбинаций. Далее вывести каждую пару на отдельной строке. Если опасных комбинаций нет — вывести только `0`.

**Пример данных в коде:**

```
substances = [10, 20, 30, 40, 50, 20, 60]dangerous_pairs = [    (10, 30),    (20, 50),    (40, 70),    (30, 10),    (60, 20),    (80, 90)]
```

**Ожидаемый вывод:**

```
3
10 30
20 50
20 60
```

**Ограничения:**

- До `100000` веществ.
- До `100000` запрещённых пар.
- Пара `(10, 30)` считается такой же, как `(30, 10)`.
- Повторения веществ в хранилище не создают дополнительных комбинаций.

## **Задача 6. Рейтинг самых ценных артефактов**

Археологи исследуют древний город. Каждый найденный артефакт имеет идентификатор, а его ценность определяется количеством обнаруженных экземпляров: чем реже артефакт, тем он ценнее.

Однако учёные хотят составить рейтинг только тех артефактов, которые встречались **не более двух раз**.

В коде задан список `artifacts`.

Напиши программу, которая:

1. Находит артефакты, встречающиеся не более двух раз.
2. Исключает из рейтинга все артефакты, найденные три раза и более.
3. Сортирует оставшиеся идентификаторы сначала по возрастанию количества появлений, а при равенстве — по убыванию идентификатора.
4. Выводит первые `k` артефактов рейтинга. Если подходящих артефактов меньше, чем `k`, выводит все подходящие.

**Формат вывода:** В первой строке вывести количество артефактов, попавших в рейтинг. Затем вывести их идентификаторы, каждый на отдельной строке.

**Пример данных в коде:**

```
artifacts = [15, 20, 15, 30, 40, 20, 50, 30, 30, 60, 70, 70, 80]k = 5
```

**Ожидаемый вывод:**

```
5
80
60
50
40
70
```

**Ограничения:**

- `1 ≤ len(artifacts) ≤ 100000`
- `1 ≤ k ≤ 1000`
- Идентификаторы — положительные целые числа.
- Один и тот же артефакт не может дважды попасть в рейтинг.

## **Задача 7. Поиск пропущенных номеров**

Автоматическая система выдаёт посылкам последовательные номера, начиная с определённого значения.

После технического сбоя часть записей была удалена, а некоторые сохранившиеся номера оказались продублированы.

Известно, что номера всех посылок должны составлять непрерывный диапазон от `start` до `end` включительно.

В коде заданы список `numbers` и два числа `start` и `end`.

Напиши программу, которая:

1. Находит все отсутствующие номера в заданном диапазоне.
2. Определяет номера, которые встречаются в списке более одного раза.
3. Игнорирует номера, находящиеся за пределами диапазона.
4. Сортирует отсутствующие и повторяющиеся номера по возрастанию.
5. Определяет количество недостающих и повторяющихся номеров. Для повторяющихся номеров учитывается количество **различных идентификаторов**, а не количество лишних записей.

**Формат вывода:** В первой строке вывести два числа: количество отсутствующих номеров и количество различных повторяющихся номеров. Во второй строке — отсутствующие номера через пробел. В третьей — повторяющиеся номера через пробел. Если соответствующий список пуст, вывести `NONE`.

**Пример данных в коде:**

```
numbers = [105, 101, 103, 101, 108, 106, 103, 110, 112, 108]start = 101end = 110
```

**Ожидаемый вывод:**

```
4 3
102 104 107 109
101 103 108
```

**Ограничения:**

- `1 ≤ len(numbers) ≤ 100000`
- `1 ≤ end - start + 1 ≤ 100000`
- Номера могут повторяться более двух раз.
- Исходный список изменять нельзя.

## **Задача 8. Самая длинная цепочка сигналов**

На исследовательскую станцию поступает список числовых кодов сигналов. Каждый код обозначает частоту, на которой удалось обнаружить активность.

Исследователей интересует самая длинная непрерывная последовательность целых частот.

Например, если обнаружены частоты `4, 7, 5, 10, 6`, то существует цепочка `4, 5, 6, 7` длиной 4.

В коде задан список `frequencies`.

Напиши программу, которая:

1. Находит самую длинную последовательность различных последовательных целых чисел.
2. Определяет длину этой последовательности.
3. Выводит все числа найденной последовательности по возрастанию.
4. Если существует несколько последовательностей одинаковой максимальной длины, выбирает ту, которая начинается с наименьшего числа.

**Формат вывода:** В первой строке вывести длину последовательности. Во второй — её элементы через пробел.

**Пример данных в коде:**

```
frequencies = [15, 3, 8, 4, 100, 5, 7, 6, 3, 20, 21, 22]
```

**Ожидаемый вывод:**

```
6
3 4 5 6 7 8
```

**Ограничения:**

- `1 ≤ n ≤ 100000`
- Числа могут быть отрицательными.
- Повторяющиеся значения не увеличивают длину цепочки.
- Постарайся придумать решение, которое не требует сортировки всего исходного списка.

## **Задача 9. Поиск минимального участка с полным набором**

На производственной линии движется последовательность деталей разных типов. Робот должен найти самый короткий непрерывный участок конвейера, на котором присутствуют **все необходимые типы деталей хотя бы по одному разу**.

В коде заданы:

- `conveyor` — список типов деталей в порядке их движения.
- `required` — список необходимых типов деталей.

Напиши программу, которая:

1. Находит самый короткий непрерывный участок списка `conveyor`, содержащий все необходимые типы.
2. Определяет начальный и конечный индексы этого участка.
3. Если подходящих участков несколько, выбирает тот, который начинается раньше.
4. Если ни один участок не подходит, выводит `NOT FOUND`.

**Формат вывода:** Вывести начальный и конечный индексы участка (нумерация с нуля), затем на следующей строке — элементы найденного участка через пробел.

**Пример данных в коде:**

```
conveyor = [2, 5, 1, 3, 5, 2, 4, 1, 5, 3, 2]required = [1, 2, 3]
```

**Ожидаемый вывод:**

```
2 5
1 3 5 2
```

**Ограничения:**

- `1 ≤ len(conveyor) ≤ 100000`
- `1 ≤ len(required) ≤ 10000`
- Список необходимых типов может содержать повторения, но каждый тип достаточно найти один раз.
- Нельзя переставлять элементы конвейера.
- Решение должно эффективно работать с большими списками.

## **Задача 10. Восстановление маршрута робота**

Робот-исследователь передаёт последовательность посещённых контрольных точек. Иногда робот возвращается в уже посещённую точку, образуя цикл.

Для анализа маршрута необходимо обнаружить **самый короткий цикл**.

Циклом считается участок маршрута, который начинается и заканчивается одинаковым идентификатором точки, причём между этими появлениями может находиться любое количество других точек.

В коде задан список `route`.

Напиши программу, которая:

1. Находит самый короткий участок маршрута, начинающийся и заканчивающийся одинаковым значением.
2. Выводит его длину, включая обе крайние точки.
3. Выводит индексы начала и конца найденного участка.
4. Если несколько циклов имеют одинаковую минимальную длину, выбирает цикл с наименьшим начальным индексом.
5. Если робот ни разу не вернулся в ранее посещённую точку, выводит `NO CYCLES`.

**Формат вывода:** В первой строке вывести длину цикла. Во второй — начальный и конечный индексы.

**Пример данных в коде:**

```
route = [10, 20, 30, 40, 20, 50, 60, 50, 70, 10]
```

**Ожидаемый вывод:**

```
3
5 7
```

**Ограничения:**

- `1 ≤ n ≤ 200000`
- Идентификаторы точек — целые числа.
- Нельзя удалять или переставлять элементы маршрута.
- Решение не должно проверять все возможные пары индексов.
