## Задача №1 «Матрица заклинаний» (без NumPy)

— Каждое заклинание в этой книге записано в виде матрицы чисел, — сказал Гэндальф. — Мне нужно проверить, не перепутал ли я строки и столбцы.

Напиши программу, которая:
1. Считывает два целых числа `N` и `M` — количество строк и столбцов матрицы.
2. Считывает `N` строк, каждая из которых содержит `M` целых чисел (числа разделены пробелами).
3. Сохраняет матрицу в виде **списка списков** (вложенного списка).
4. Выводит исходную матрицу в виде строк (каждый ряд с новой строки).
5. Находит и выводит **сумму всех элементов** матрицы.
6. Находит и выводит **максимальный элемент** в каждой строке.

**Формат ввода**
1. Два числа N и M.
2. N строк по M чисел.

**Формат вывода**
Сначала N строк с элементами матрицы. Затем строка `Сумма: <число>`. Затем N строк с максимальными элементами каждой строки в формате: `Макс в строке <i>: <значение>`.

| Ввод | Вывод |
| :--- | :--- |
| 2 3 | 1 2 3 |
| 1 2 3 | 4 5 6 |
| 4 5 6 | Сумма: 21 |
| | Макс в строке 0: 3 |
| | Макс в строке 1: 6 |

## Задача №2 «Боевая матрица» (с NumPy)

— Я хочу проанализировать матрицу боевых характеристик отряда, — сказал Арагорн. — Но делать это вручную слишком долго. Используй силу библиотеки NumPy.

**Инструкция по подключению NumPy в IDLE:**
1. **Установка:** открой командную строку (Windows: `Win + R` → `cmd`; macOS: Terminal). Введи команду:
   `pip install numpy`
   *(Если у тебя несколько версий Python, лучше использовать `python -m pip install numpy`).*
2. **Подключение в коде:** после установки открой IDLE (File → New File), в начале программы напиши:
   `import numpy as np`
   Теперь ты можешь использовать функции NumPy, вызывая их через `np.`.

Напиши программу, которая:
1. Считывает два целых числа `N` и `M` — размеры матрицы.
2. Считывает `N` строк по `M` целых чисел.
3. Создаёт из этих данных **матрицу NumPy** (используй `np.array()`).
4. Выводит исходную матрицу и её **размерность** (свойство `.shape`).
5. Выводит **транспонированную матрицу** (свойство `.T`).
6. Выводит **сумму всех элементов** (метод `.sum()`).
7. Выводит **среднее значение** (метод `.mean()`).
8. Выводит **максимум в каждой строке** (метод `.max(axis=1)`).

**Формат ввода**
1. Два числа N и M.
2. N строк по M чисел.

**Формат вывода**
Исходная матрица, её размерность, транспонированная матрица, сумма, среднее и максимумы по строкам в формате:
`Сумма: <число>`
`Среднее: <число>`
`Максимумы по строкам: <список>`

| Ввод | Вывод |
| :--- | :--- |
| 2 3 | [[1 2 3] |
| 1 2 3 |  [4 5 6]] |
| 4 5 6 | Размерность: (2, 3) |
| | [[1 4] |
| |  [2 5] |
| |  [3 6]] |
| | Сумма: 21 |
| | Среднее: 3.5 |
| | Максимумы по строкам: [3 6] |
