### Задача №1 «Эхо Сарумана»

**Сюжет:**
— Гэндальф, — прошептал Фродо, — мы заблудились в лесу Фангорн. Кажется, эти деревья повторяют всё, что мы говорим...
— Это не деревья, — мрачно ответил маг. — Это магия Сарумана. Он искажает слова. Нам нужно следить за эхом.

**Задание:**
Напиши программу, которая анализирует "эхо" Сарумана.
Программа должна считывать строки до тех пор, пока не встретит слово **"Мордор"** (конец пути).
Для каждой введенной строки (кроме последней) нужно проверить:
1. Если длина строки **чётная**, вывести слово **"ЭХО"** и саму строку.
2. Если длина строки **нечётная**, вывести слово **"ТИШИНА"** и количество символов в этой строке.
3. Если в строке встречается слово **"кольцо"** (в любом регистре), вывести **"ВНИМАНИЕ! ОПАСНОСТЬ!"** (и не выполнять пункты 1 и 2 для этой строки).

**Формат ввода:**
Строки, пока не будет введена строка "Мордор".

**Формат вывода:**
Для каждой строки (кроме "Мордор") вывести результат обработки на новой строке.

**Пример работы:**
| Ввод | Вывод |
| :--- | :--- |
| Привет | ТИШИНА 6 |
| Это кольцо | ВНИМАНИЕ! ОПАСНОСТЬ! |
| Идем домой | ЭХО Идем домой |
| Мордор | |

### Задача №2 «Жребий Голлума» (Загадка в темноте)

**Сюжет:**
— Нет, нет, моя прелесть! — шипел Голлум. — Мы не скажем, куда идти, пока ты не отгадаешь нашу загадку. Ты должен угадать число, которое я загадал. Или мы съедим тебя, да, сожрём!

**Задание:**
Голлум загадал число в диапазоне от 1 до 100 включительно.
Напиши программу, которая будет считывать числа (попытки угадать), пока не введет загаданное число (**42**).
Программа должна подсказывать:
*   Если введенное число **меньше** загаданного, вывести: **"Меньше! Моя прелесть хочет больше!"**
*   Если введенное число **больше** загаданного, вывести: **"Слишком много! Моя прелесть хочет меньше!"**
*   Если число угадано, вывести: **"ДА! Моя прелесть! Ты свободен!"** и завершить работу.

**Формат ввода:**
Числа (каждое на новой строке), пока не будет введено 42.

**Формат вывода:**
Текстовые подсказки для каждого числа.

**Пример работы:**
| Ввод | Вывод |
| :--- | :--- |
| 10 | Меньше! Моя прелесть хочет больше! |
| 50 | Слишком много! Моя прелесть хочет меньше! |
| 42 | ДА! Моя прелесть! Ты свободен! |

### Задача №3 «Счёт Братства»

**Сюжет:**
— Нас девять, — сказал Элронд. — Девять спутников против девяти всадников. Но силы не равны. Нам нужно следить за тем, кто остался в строю, а кто пал духом.

**Задание:**
Напиши программу, которая подсчитывает "боевой дух" отряда.
Сначала вводится количество воинов в отряде (целое число `N`).
Затем вводится `N` строк с именами воинов.
Программа должна посчитать, сколько воинов имеют в имени букву **"а"** (строчную или заглавную).
*   Если таких воинов **больше половины** от общего числа `N`, вывести: **"ОТРЯД ГОТОВ К БИТВЕ"**.
*   В противном случае вывести: **"НАДО ПЕРЕСЧИТАТЬ СОСТАВ"**.
*   В конце вывести общее количество воинов, в имени которых есть буква "а".

**Формат ввода:**
1. Число N.
2. N строк с именами.

**Формат вывода:**
Статус отряда и число воинов с буквой "а".

**Пример работы:**
| Ввод | Вывод |
| :--- | :--- |
| 5 | ОТРЯД ГОТОВ К БИТВЕ |
| Арагорн | 3 |
| Леголас | |
| Гимли | |
| Боромир | |
| Гэндальф | |

| Ввод | Вывод |
| :--- | :--- |
| 5 | НАДО ПЕРЕСЧИТАТЬ СОСТАВ |
| Арагорн | 2 |
| Леголас | |
| Гимли | |
| Боромир | |
| Саурон | |

*(Пояснение: "Арагорн" и "Гэндальф" содержат "а". Их 2 из 5. 2 не больше половины (2.5), значит "НАДО ПЕРЕСЧИТАТЬ".)*
