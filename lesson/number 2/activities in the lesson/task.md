# Часть 1. Задания БЕЗ массивов

## Задача №4 «Ворота Мории»

— Скажи, друг, и войди, — прочитал Гэндальф древние письмена на камне. — Здесь нужен пароль. Но не простой, а произнесённый с правильной интонацией.

Напиши программу, которая проверяет пароль. Считывается одна строка — попытка пароля. Пароль считается верным, если одновременно выполняются три условия:
1. Длина строки **ровно 8 символов**.
2. Строка начинается с буквы **"М"** (заглавной).
3. Строка заканчивается на **"!"**.

Если пароль верный — вывести **"ВОРОТА ОТКРЫТЫ"**, иначе — **"НЕВЕРНЫЙ ПАРОЛЬ"**.

**Формат ввода**
Одна строка.

**Формат вывода**
Одна строка с результатом.

| Ввод | Вывод |
| :--- | :--- |
| Мория!х | НЕВЕРНЫЙ ПАРОЛЬ |
| Мория123! | ВОРОТА ОТКРЫТЫ |

## Задача №5 «Счёт орков»

— Сколько их там? — спросил Леголас, натягивая тетиву.
— Много, — ответил Арагорн. — Но мы должны знать точно.

Напиши программу, которая считает количество орков в отряде. Сначала вводится число `N` — сколько разведчиков донесли сведения. Затем вводится `N` чисел — сколько орков увидел каждый разведчик. Программа должна посчитать **сумму** всех донесений и вывести её.

Если итоговая сумма **больше 100**, дополнительно вывести **"ТРЕВОГА! БОЛЬШОЙ ОТРЯД!"**.

**Формат ввода**
1. Число N.
2. N чисел (каждое на новой строке).

**Формат вывода**
Сумма всех чисел, и при необходимости — предупреждение.

| Ввод | Вывод |
| :--- | :--- |
| 3 | 60 |
| 10 | |
| 20 | |
| 30 | |

| Ввод | Вывод |
| :--- | :--- |
| 3 | ТРЕВОГА! БОЛЬШОЙ ОТРЯД! |
| 50 | 150 |
| 50 | |
| 50 | |

## Задача №6 «Обратный путь»

— Мы шли слишком долго, — сказал Сэм. — Может, вернёмся?
— Нет, — ответил Фродо. — Но запомнить дорогу стоит. На случай, если придётся идти назад.

Напиши программу, которая считывает строку и выводит её **в обратном порядке** (задом наперёд). Использовать срезы `[::-1]` **нельзя** — только цикл.

**Формат ввода**
Одна строка.

**Формат вывода**
Эта же строка, записанная в обратном порядке.

| Ввод | Вывод |
| :--- | :--- |
| Шир | риШ |
| Мордор | родроМ |

# Часть 2. Задания С коллекциями

## Задача №7 «Список Братства» (Списки)

— Нас девять, — сказал Элронд. — Впишите свои имена в свиток, чтобы память о вас осталась.

Напиши программу, которая:
1. Считывает число `N` — количество воинов.
2. Считывает `N` имён и сохраняет их в **список**.
3. Выводит список на экран.
4. Выводит количество имён в списке.
5. Выводит **первое** и **последнее** имя.

**Формат ввода**
1. Число N.
2. N строк с именами.

**Формат вывода**
Список, количество, первое и последнее имя.

| Ввод | Вывод |
| :--- | :--- |
| 3 | ['Арагорн', 'Леголас', 'Гимли'] |
| Арагорн | 3 |
| Леголас | Арагорн |
| Гимли | Гимли |

## Задача №8 «Координаты Средиземья» (Кортежи)

— Каждый город имеет свои координаты, — объяснил Гэндальф. — И их нельзя менять. Запомни это.

Напиши программу, которая:
1. Считывает число `N` — количество городов.
2. Для каждого города считывает название и два числа (x, y) — координаты.
3. Сохраняет каждый город в виде **кортежа** `(название, x, y)`.
4. Выводит все кортежи на экран.
5. Выводит координаты **первого** города отдельно.

**Формат ввода**
1. Число N.
2. Для каждого города: название, x, y (каждое на новой строке).

**Формат вывода**
Все кортежи, затем координаты первого города.

| Ввод | Вывод |
| :--- | :--- |
| 2 | ('Шир', 10, 20) |
| Шир | ('Мордор', 50, 60) |
| 10 | 10 20 |
| 20 | |
| Мордор | |
| 50 | |
| 60 | |

## Задача №9 «Уникальные кольца» (Множества)

— Каждое кольцо уникально, — сказал Келебримбор. — Но некоторые из них похожи. Нам нужно знать, сколько разных колец мы выковали.

Напиши программу, которая:
1. Считывает число `N` — количество колец.
2. Считывает `N` названий колец (могут повторяться).
3. Сохраняет их в **множество** (повторы автоматически убираются).
4. Выводит количество **уникальных** колец.
5. Выводит само множество.

**Формат ввода**
1. Число N.
2. N строк с названиями.

**Формат вывода**
Количество уникальных названий и само множество.

| Ввод | Вывод |
| :--- | :--- |
| 5 | 3 |
| Нарья | {'Нарья', 'Ненья', 'Вилья'} |
| Нарья | |
| Ненья | |
| Вилья | |
| Нарья | |

## Задача №10 «Перепись Хоббитов» (Словари)

— Каждый хоббит должен быть учтён, — строго сказал Бильбо. — Имя — и сколько он съел пирогов.

Напиши программу, которая:
1. Считывает число `N` — количество хоббитов.
2. Для каждого хоббита считывает имя и число съеденных пирогов.
3. Сохраняет данные в **словарь** `{имя: количество пирогов}`.
4. Выводит словарь.
5. Выводит имя хоббита, съевшего **больше всех** пирогов.

**Формат ввода**
1. Число N.
2. Для каждого: имя, число пирогов (каждое на новой строке).

**Формат вывода**
Словарь и имя рекордсмена.

| Ввод | Вывод |
| :--- | :--- |
| 3 | {'Бильбо': 5, 'Сэм': 8, 'Мерри': 3} |
| Бильбо | Сэм |
| 5 | |
| Сэм | |
| 8 | |
| Мерри | |
| 3 | |
