## Задача №1 «Код для Бэт-компьютера»

— Бэт-компьютер принимает только код из цифр, — сказал Альфред. — Но Бэтмен прислал что-то странное. Проверь, можно ли это вообще использовать.

Напиши программу, которая:
1. Считывает одну строку — предполагаемый код.
2. С помощью цикла проверяет, состоит ли строка **только из цифр** (символы `0`–`9`).
3. Если в строке есть хотя бы один нецифровой символ — вывести `ДОСТУП ЗАПРЕЩЁН`.
4. Если вся строка состоит из цифр — вывести `ДОСТУП РАЗРЕШЁН`.

Использовать метод `.isdigit()` **нельзя** — только цикл и сравнение символов.

**Формат ввода**
Одна строка.

**Формат вывода**
Одна строка с результатом.

| Ввод | Вывод |
| :--- | :--- |
| 1940 | ДОСТУП РАЗРЕШЁН |
| 19x40 | ДОСТУП ЗАПРЕЩЁН |

## Задача №2 «Досье на врагов Готэма» (усложнённая)

— У Бэтмена много врагов, — сказал Альфред. — Но не все они одинаково опасны. Запиши их и расставь приоритеты.

Напиши программу, которая:
1. Считывает число `N` — сколько врагов будет введено.
2. В цикле считывает `N` строк — по одному имени врага.
3. Для каждого имени выводит строку в формате: `<ИМЯ> — враг Готэма`, где имя записано **в верхнем регистре**.
4. Дополнительно для каждого имени:
   - если в имени есть буква `"о"` (в любом регистре) — добавить в конец строки ` [ОСОБО ОПАСЕН]`;
   - иначе — добавить ` [наблюдение]`.
5. В конце вывести две строки:
   - `Всего врагов: <N>`
   - `Особо опасных: <K>`, где `K` — сколько врагов получили метку `[ОСОБО ОПАСЕН]`.

**Формат ввода**
1. Число N.
2. N строк с именами.

**Формат вывода**
N строк с описанием, затем две итоговые строки.

| Ввод | Вывод |
| :--- | :--- |
| 3 | ДЖОКЕР — враг Готэма [ОСОБО ОПАСЕН] |
| Джокер | БЭЙН — враг Готэма [наблюдение] |
| Бэйн | ЗАГАДОЧНИК — враг Готэма [ОСОБО ОПАСЕН] |
| Загадочник | Всего врагов: 3 |
| | Особо опасных: 2 |

## Задача №3 «Двойной шифр Бэтмена» (усложнённая)

— Иногда Бэтмен говорит загадками, — сказал Гордон. — И кодовых слов у него несколько. Нужно посчитать каждое.

Напиши программу, которая:
1. Считывает одну строку — фразу Бэтмена.
2. Считывает одну букву — первый кодовый символ.
3. Считывает ещё одну букву — второй кодовый символ.
4. С помощью **одного цикла** по строке считает:
   - сколько раз встречается первый символ,
   - сколько раз встречается второй символ,
   - сколько раз они встречаются **вместе** (то есть общее число вхождений обоих символов).
5. Сравнение вести **без учёта регистра**.
6. Вывести три строки:
   - `Первый символ: <A>`
   - `Второй символ: <B>`
   - `Вместе: <C>`

**Формат ввода**
1. Строка.
2. Один символ.
3. Один символ.

**Формат вывода**
Три строки с числами.

| Ввод | Вывод |
| :--- | :--- |
| Бэтмен бьёт Бэйна | Первый символ: 3 |
| б | Второй символ: 1 |
| э | Вместе: 4 |

**Пояснение к примеру:**
В строке `Бэтмен бьёт Бэйна` (в нижнем регистре — `бэтмен бьёт бэйна`):
- буква `б` встречается 3 раза: в `Бэтмен`, `бьёт`, `Бэйна`;
- буква `э` встречается 1 раз: в `Бэтмен`;
- вместе — 4.
