# Задание №1 «Ход конём по нику»

— Каждый герой ходит по-своему, — сказал Инвокер. — А я хочу видеть, как буквы ника «прыгают» по строке.

Напиши программу, которая:

1. Считывает одну строку — ник игрока (только русские буквы, без пробелов).
2. Считывает одно целое число `K` — шаг «прыжка».
3. Строит новую строку, обходя исходную **по кругу** с шагом `K`: начинаем с позиции `0`, затем `(0 + K) % len`, затем `(0 + 2K) % len` и так далее, пока не вернёмся в стартовую позицию.
4. Выводит получившуюся строку.

**Важно:** обход должен закончиться, когда мы **вернёмся в позицию `0`** — то есть длина результата может быть **меньше** длины исходной строки, если `K` и длина строки не взаимно просты.

**Подсказка:** позицию храни в переменной и обновляй через `% len(line)`. Остановись, когда снова окажешься в `0` (но не на первом шаге).

**Формат ввода**

1. Строка.
2. Целое число K.

**Формат вывода**
Одна строка.

| Ввод     | Вывод |
| :------- | :---- |
| DotaDota | DtDt  |
| 2        |       |

Пояснение: длина `8`, `K = 2`. Позиции: `0 (D)`, `2 (t)`, `4 (D)`, `6 (t)`, `0` — стоп. Результат: `DtDt`.

# Задание №2 «Сжатие повторов»

— В логах матча слишком много одинаковых символов, — сказал Тоби. — Сожми их.

Напиши программу, которая:

1. Считывает одну строку — лог.
2. Сжимает её: **подряд идущие одинаковые символы** заменяются на `<символ><количество>`. Если символ встречается **один раз** — он остаётся **без числа**.
3. Выводит сжатую строку.

**Примеры:**

- `aaa` → `a3`
- `aabbbcc` → `a2b3c2`
- `abc` → `abc`
- `aabb` → `a2b2`
- `aaabbbbaaa` → `a3b4a3`

**Ограничения:**

- Нельзя использовать `itertools.groupby`.
- Нельзя превращать строку в список.
- Разрешено использовать **только один проход** по строке и переменные для «текущего символа» и «счётчика».

**Подсказка:** иди по строке циклом `for char in line`, но **дополнительно** обработай последнюю группу **после** цикла — иначе она потеряется.

**Формат ввода**
Одна строка.

**Формат вывода**
Одна строка — сжатая.

| Ввод     | Вывод  |
| :------- | :----- |
| aaabbbcc | a3b3c2 |
| abc      | abc    |
| a        | a      |
| aaaa     | a4     |
